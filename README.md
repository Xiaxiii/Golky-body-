# 酒馆内置网易云播放器

给 SillyTavern 1.19.0 加一个页面内的网易云音乐播放器：

- **后台保活**：音乐在酒馆页面里播放，iOS 就不会挂起这个页面。歌停了，多半说明页面被回收了。
- **锁屏看生成状态**：生成期间锁屏 / 控制中心的副标题显示「酒馆 · 正在生成…」，完成后显示「酒馆 · 回复已完成」，不用切回 Safari。
- **不拖慢启动**：启动时只多加载两个小文件（`manifest.json` 和 `index.js`），不发任何接口请求；播放器界面和播放逻辑点开后才加载。

不改动柏宝箱、柏宝库和酒馆本身的任何文件。

## 安装

按 [INSTALL.md](INSTALL.md) 的命令，在阿里云 Workbench 的 **Shell** 模式里依次整段粘贴（Agent 模式会把粘贴的内容交给 AI 改写，长命令会被截断），每段出现 `OK` 再做下一段。
文件内容切成了每段 5KB 左右的小段，每段单独校验。卸载命令也在 INSTALL.md 最后。

## 使用说明

1. iPhone 上刷新酒馆。点输入框左边的魔法棒 →「网易云音乐」，打开播放器。
2. **登录**：「账号/设置」→「扫码登录」。手机自己的相机扫不到自己屏幕上的码，所以：
   截图 → 打开网易云 App →「扫一扫」→ 右上角从相册选这张截图 → 在 App 里确认 → 回到酒馆。
   也可以点「复制登录链接」作为备选。不登录也能搜歌，但只能放免费歌曲；VIP 歌需要登录 VIP 账号。
3. **放歌**：「搜索」里点歌名立刻播放，点 ＋ 加到队列末尾；「歌单」里打开「我喜欢的音乐」，点「播放全部」或「随机播放」。
   大歌单会在快放完时自动接着加载后面的歌。
4. 输入框上方会出现一条迷你播放条：播放/暂停、下一首、点歌名展开面板。锁屏和控制中心可以播放、暂停、上一首、下一首、拖进度。
5. 页面被回收后重新打开：迷你播放条会显示「继续播放」，点一下就从上次的位置接着放（iOS 不允许网页自己出声，所以必须点一下）。
6. 不想用了：「账号/设置」→「停止并关闭」，迷你播放条会隐藏，下次从魔法棒菜单再打开。

### 和柏宝箱一起用

- **关掉柏宝箱的「生成中静音保活」**。音乐本身就在保活；两个声音同时抢，iOS 会让其中一个停下来。
- **「生成完成提示音」先保持原样实测一次**：生成完成时音乐如果被打断，播放器会在 1 秒内自动接着放（「账号/设置」里的「生成完成前后音乐被提示音打断时，自动接着放」，默认开）。
  如果实测还是会断、或者觉得那一下中断不舒服，就关掉柏宝箱的提示音——锁屏上的「回复已完成」就是无声的完成提示。
- 柏宝箱的「消息后台生成」照常用。播放器不包装 `fetch`，不改生成请求。

### 生成状态是怎么判断的

在 1.19.0 源码里核对过，酒馆提供这些事件：`generation_started`、`stream_token_received`、`message_received`、
`generation_ended`、`generation_stopped`。**没有单独的「生成失败」事件**，失败时也只会触发 `generation_ended`。所以：

| 情况 | 锁屏副标题 |
|---|---|
| 开始生成（不含扩展在后台跑的 quiet 生成） | 酒馆 · 正在生成… |
| 生成结束并收到了新消息 | 酒馆 · 回复已完成 |
| 点了停止 | 酒馆 · 已停止生成 |
| 生成结束但没收到新消息（多半是出错了） | 酒馆 · 生成已结束 |

另外监听了酒馆在生成期间给页面加的 `data-generating` 标记作为备用信号：万一柏宝箱的后台生成模式下事件不触发，也能显示状态。
显示「已完成」后，过 3 分钟（可在设置里改）或回到酒馆页面时，恢复显示歌手名。

柏宝箱的「消息后台生成」我看不到源码，没法事先确认事件会不会触发。「账号/设置」最下面有**事件日志**，记录每次生成事件、暂停、切歌和离开/回到页面，测试时看这里就知道哪个信号来了。

## 分阶段在 iPhone 上实测

**第一阶段：装好、能放**
1. 用焦香鸡翅的「加载体检」对比装前装后：启动阶段只多了 `netease-player/manifest.json` 和 `netease-player/index.js` 两个文件请求，没有 `/api/plugins/netease-player/` 请求。
2. 扫码登录成功，能搜歌，能打开「我喜欢的音乐」并播放。
3. 柏宝箱「消息后台生成」、第三方 QR 等功能正常。

**第二阶段：后台连续播放**
4. 锁屏后连续播放至少 3 首，切歌不断。
5. 锁屏 / 控制中心显示歌名和封面，播放、暂停、下一首能用。
6. 切到别的 App 再回来，页面没有重新加载（事件日志里没有新的「页面加载」），生成的回复完整。
7. 让页面被回收后重开，迷你条显示「继续播放」，点一下接着放。

**第三阶段：锁屏生成状态**
8. 播放中发送消息，马上锁屏，看锁屏副标题是否变成「正在生成…」→「回复已完成」。
9. 回到酒馆，打开「账号/设置」看事件日志：有没有「开始生成」「生成结束 done」，有没有「暂停 被系统或其他声音打断」「自动恢复播放」。

第 8 条要看 iOS 是否会在页面处于后台时刷新锁屏信息，这一点只能实测。如果锁屏不刷新，这个功能就做不到，播放本身不受影响。

## 已知风险

- 网易云没有给个人用的播放接口，这里用的是社区维护的非官方接口（`@neteasecloudmusicapienhanced/api` 4.41.1）。网易云改版时可能失效，需要更新依赖或修代码。
- 有一定概率触发账号风控（比如要求验证）。只做了扫码登录，没有密码登录。
- 网易云有时会拦截云服务器 IP（返回 460）。插件会把手机自己的 IP 一起传过去，一般能避开；安装时的自检用的是服务器 IP，自检报 460 不代表手机上用不了。
- 歌曲地址有时效（约 20 分钟），播放器按需获取、不缓存；暂停很久再继续时如果地址过期，会自动重新获取。
- 无版权、需要 VIP 的歌取不到地址，会提示并跳过；连续 5 首都放不了就停下。未登录 VIP 时只有试听片段的歌默认也会跳过（设置里可改）。
- 页面是 HTTP，所以「复制登录链接」用的是旧的复制方式；复制不了时会显示链接让你长按手动复制。以后上了 HTTPS，网易云返回的 http 音频地址需要改成 https（服务端 `lib.mjs` 的 `getSongUrl`）。
- 网易云登录 cookie 只存在服务器 `plugins/netease-player/data/`（目录权限 700，文件 600），不会返回给浏览器。

## 文件

```
server/netease-player/      → 服务器 /root/SillyTavern/plugins/netease-player/
  index.mjs                   路由（/api/plugins/netease-player/*，全部 POST，受酒馆登录和 CSRF 保护）
  lib.mjs                     网易云接口封装（第一次使用时才载入接口包）
  selftest.mjs                安装后自检
extension/netease-player/   → 服务器 /root/SillyTavern/public/scripts/extensions/third-party/netease-player/
  index.js                    启动时唯一运行的文件：菜单项、生成事件、迷你播放条
  engine.js                   播放引擎（点开或点播放后才加载）
  panel.js                    展开面板（点开后才加载）
tools/build-install.mjs     生成 INSTALL.md 里的粘贴命令
tests/                      端到端测试（用替身代替网易云接口）
```

改了代码后运行 `node tools/build-install.mjs` 重新生成 INSTALL.md。
